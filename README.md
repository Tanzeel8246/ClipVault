# 📋 ClipVault (کلپ والٹ)

> **All-in-One Smart Clipboard Manager, VaultBoard Native Keyboard & Cross-Platform Sync Suite**  
> موبائل ایپ، والٹ بورڈ کی بورڈ، کروم ایکسٹینشن اور ویب کمپیئن کا مکمل مجموعہ۔

---

## 🌟 پروجیکٹ کا جائزہ (Project Overview)

**ClipVault** ایک جدید اور طاقتور کلپ بورڈ مینیجر اور ٹائپنگ سوٹ ہے جو صارفین کو لامحدود کلپ بورڈ ہسٹری، زیرو-نالج اینڈ-ٹو-اینڈ اینکرپشن (E2EE)، اور 100% آف لائن رومن اردو سے نستعلیق لائیو ٹرانسلیٹریشن فراہم کرتا ہے۔

یہ ریپوزٹری مکمل پروجیکٹ پر مشتمل ہے:
1. **موبائل ایپ اور والٹ بورڈ کی بورڈ (Mobile App & Native Keyboard):** React Native + Expo + Native Kotlin/Java برائے Android 16 (API 36)۔
2. **کروم ایکسٹینشن (Chrome Extension - `/extension`):** Manifest V3 ایکسٹینشن برائے اردو فونٹ کسٹمائزیشن، کلپ بورڈ ہسٹری، اور گوگل ڈرائیو سنک۔
3. **ڈیسک ٹاپ ویب کمپیئن (Web Companion - `/web`):** React 19 + Vite + Tailwind CSS ویب ایپلیکیشن برائے پی سی براؤزر ایکسیس۔

## 🚀 اہم خصوصیات (Key Features)

### 1. موبائل ایپ اور نیٹو کی بورڈ (ClipVault & VaultBoard)
- **⚡ زیرو لیٹنسی والٹ بورڈ (VaultBoard):** 0ms لیٹنسی، نان بلاکنگ بیک گراؤنڈ تھریڈنگ اور 120 FPS رسپانس۔
- **✍️ 100% آف لائن رومن اردو ٹرانسلیٹریشن:** بغیر انٹرنیٹ رومن اردو سے خط نستعلیق میں لائیو تبدیلی۔
- **🧠 جیمنی اے آئی اسسٹنٹ (Gemini AI):** ون کلک اسمارٹ کلپ سمرائزیشن اور پروف ریڈنگ۔
- **🔢 پرسنلائزڈ کی بورڈ ٹولز:** مکمل نمبر رو (0-9)، ٹیکسٹ ایڈیٹنگ ٹول بار (کاپی، کٹ، پیسٹ، نیٹو ان ڈو/ری ڈو)۔
- **🕶️ انکوگنیٹو پرائیویسی موڈ:** پاس ورڈز اور حساس ڈیٹا کو خودکار طور پر کلپ ہسٹری سے محفوظ رکھنا۔
- **📱 ہوم اسکرین وجیٹس:** ہوم اسکرین سے ایک کلک پر حالیہ کلپس کاپی کرنے کی سہولت۔
- **🛡️ 16KB میموری پیج الائنمنٹ:** Android 16 (API 36) اور Google Play Store کی تمام ضروریات سے 100% مطابقت۔

### 2. گوگل کروم ایکسٹینشن (`/extension`)
- **🌐 اردو ویب کسٹمائزر:** کسی بھی ویب سائٹ کے فونٹ کو 10+ خوبصورت نستعلیق اور نسخ فونٹس میں لائیو تبدیل کریں۔
- **🔄 گوگل ڈرائیو بیک اپ سنک:** موبائل پر محفوظ شدہ کلپس کو براہ راست اپنے پی سی کروم براؤزر میں دیکھیں اور کاپی کریں۔
- **📸 اسکرین کیپچر اور آڈیو ریکارڈر:** ویب پیجز اور نوٹس فوری کیپچر کرنے کا ٹول۔

### 3. ڈیسک ٹاپ ویب کمپیئن (`/web`)
- **💻 براؤزر ایکسیس:** بغیر کسی سافٹ ویئر انسٹال کیے گوگل اکاؤنٹ کے ذریعے کلاؤڈ کلپس تک رسائی۔
- **🔐 کلائنٹ سائیڈ ڈیکرپشن:** AES-256 اینکرپشن کے ساتھ محفوظ سنک پاس ورڈ کی توثیق۔

## 🛠️ انسٹالیشن اور چلانے کا طریقہ (Getting Started)

### موبائل ایپ (React Native & Android)
```bash
# ڈیپینڈینسیز انسٹال کریں
npm install

# اینڈرائیڈ پر چلائیں
npx expo run:android

# ریلیز اے پی کے (APK) بنائیں
build-apk.bat
```

### کروم ایکسٹینشن (Chrome Extension)
1. گوگل کروم میں `chrome://extensions/` کھولیں۔
2. اوپر دائیں جانب **Developer mode** آن کریں۔
3. **Load unpacked** پر کلک کریں اور اس ریپوزٹری کا `extension` فولڈر منتخب کریں۔

### ویب کمپیئن (Web Companion)
```bash
cd web
npm install
npm run dev
```

## 🔒 پرائیویسی اور سیکیورٹی (Security & Privacy)
- **Zero Knowledge Architecture:** آپ کا ڈیٹا صرف آپ کے پاس ہے، ہم کسی بیرونی سرور پر آپ کا کلپ بورڈ ڈیٹا محفوظ نہیں کرتے۔
- **E2EE گوگل ڈرائیو سنک:** کلپس گوگل ڈرائیو کے پوشیدہ AppData فولڈر میں AES-256 سے اینکرپٹ ہو کر سنک ہوتے ہیں۔
